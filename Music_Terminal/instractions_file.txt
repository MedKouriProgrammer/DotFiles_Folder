Run music on terminal:
source video: https://www.youtube.com/watch?v=iGW0EpsUb7E
source code:https://github.com/Sin-cy/dotfiles/blob/main/mpd/.config/mpd/mpd.conf
            https://github.com/Sin-cy/dotfiles/tree/main/rmpc/.config/rmpc

Requarement:
1- install mpd & mpc & rmpc.

-----------------------
sudo pacman -S mpd mpc 

yay -S rmpc
-----------------------

-----------------------------------------------------------------------------------
2- Create the folder for mpd and his config-file.

-----------------------
mkdir -p ~/.config/mpd
mkdir ~/.config/mpd/playlists

nano ~/.config/mpd/mpd.conf
-----------------------

Now past this code in → ~/.config/mpd/mpd.conf :
-----------------------
music_directory     "~/Music"
playlist_directory  "~/.config/mpd/playlists"
db_file             "~/.config/mpd/mpd.db"
log_file            "~/.config/mpd/mpd.log"
pid_file            "~/.config/mpd/mpd.pid"
state_file          "~/.config/mpd/mpdstate"
follow_outside_symlinks "yes"
follow_inside_symlinks  "yes"

auto_update         "yes"
bind_to_address     "localhost"
port                "6600"

audio_output {
    type            "pulse"
    name            "pulse audio"
}
-----------------------

4- Run mpd, It don’t open the ui music it just run the mpd.
-----------------------
mpd
# to run the basic rmpd
rmpd
-----------------------
# If you add a music in the Music folder and you don’t found it in rmpd you have to write `mpc update` and `rmpc`.

-------------------------------------------------------------------------------
5- Now to make the configuration of rmpc in another side we have to create rmpc_folder and config.ron:
-----------------------
mkdir -p ~/.config/rmpc

nano ~/.config/rmpc/config.ron
-----------------------
